# Prompt Engineering

Prompt engineering for healthcare should be structured, auditable, and cautious. A good prompt does more than ask for an answer; it defines role, context, limits, output format, and escalation rules.

## Practical Prompt Pattern

1. Define the clinical or operational role.
2. Provide only the necessary context.
3. Ask for structured output.
4. Include uncertainty and safety instructions.
5. Require next-step recommendations instead of overconfident conclusions.

## Example Use Cases

- Patient education summaries in simple language.
- OPD follow-up message drafts.
- Differential diagnosis thinking checklists.
- Medical article summarization.
- Clinic automation instructions for n8n or Python scripts.

## Core Rule

AI should support professional judgment, not replace it. Prompts must make that boundary visible.

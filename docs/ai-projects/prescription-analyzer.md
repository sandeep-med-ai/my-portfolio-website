# Prescription Analyzer

Prescription analysis can help patients and clinicians read medication plans more clearly. The idea is to convert handwritten or typed prescriptions into structured, understandable summaries.

## Features

- Medicine name extraction.
- Dose and timing explanation.
- Duplicate or unclear instruction flags.
- Patient-friendly summary.
- Follow-up reminder generation.

## Safety Boundary

The tool should highlight uncertainty and advise confirmation with the treating clinician or pharmacist whenever handwriting, dose, or drug name is unclear.
